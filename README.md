# NursetMobile — курсовая работа

Android-приложение для небольшого магазина: каталог, складские остатки и обработка заказов.
Тема: «Разработка информационной системы учёта товаров и заказов на Kotlin».

## Возможности

- Регистрация клиента: имя и телефон с проверкой заполнения.
- Поиск клиентов по имени или телефону, история заказов выбранного клиента.
- Создание заказа: подбор по названию и категории, ввод количества, расчёт стоимости. Клиент необязателен.
- Статусы: Новый → В обработке → Завершён; активный заказ можно отменить.
- При создании заказа товары списываются со склада; при отмене возвращаются.
- Каталог товаров и категорий, поиск по русским и латинским названиям, фильтр по категории.
- Цена и название товара, имя клиента сохраняются в заказе на момент создания.
- Светлая и тёмная темы, локальное хранение без регистрации аккаунта и сервера.

## Запуск

Откройте проект в Android Studio, дождитесь синхронизации Gradle и запустите `app`
на устройстве или эмуляторе Android 8.0+ (API 26). Используйте JDK из Android Studio.

```powershell
.\gradlew.bat assembleDebug
.\gradlew.bat testDebugUnitTest
.\gradlew.bat lintDebug
```

APK после сборки: `app/build/outputs/apk/debug/app-debug.apk`.

## Основной сценарий

1. На главной нажмите «Новый заказ» или откройте «Заказы» → «+».
2. Выберите товары: доступны поиск и категории. Нажмите «Готово».
3. Измените количество кнопками или нажмите на число и введите его с клавиатуры.
4. При необходимости выберите клиента. Покупку можно оформить без регистрации клиента.
5. Проверьте закреплённую внизу сумму и нажмите «Создать заказ» — откроется его карточка.
6. Переведите заказ в обработку, выполните или отмените. При отмене товары вернутся на склад.

На пустой базе создаются демонстрационные категории, товары и заказы. Данные хранятся
локально. Клиентская база дополняет товарный учёт и позволяет видеть историю покупок.

## Работа с остатками

На главной карточки «Заканчиваются» и «Нет в наличии» открывают соответствующие списки.
В каталоге можно совместить поиск, категорию и фильтр по наличию. «Заканчиваются» означает
от 1 до 3 единиц; нулевые остатки показаны отдельно. Счётчики показывают число наименований.

Кнопка «Пополнить остаток» добавляет поступившее количество к текущему остатку в транзакции,
не перезаписывая название и цену товара. Это простая операция пополнения, а не журнал поставок.

## Устройство проекта

Kotlin, Jetpack Compose, Material 3, Room, Coroutines / StateFlow, MVVM.

`UI → ViewModel → Repository → DAO → Room (SQLite)`

Код находится в `app/src/main/java/com/nursetmobile`:

- `data/entity`, `data/dao` — клиенты, товары, категории, заказы и позиции заказа;
- `data/repository` — проверка данных и бизнес-правила;
- `viewmodel` — состояние экранов и действия пользователя;
- `ui` — экраны и навигация;
- `domain` — статусы и разрешённые переходы.

База версии 2 обновляется с версии 1 миграцией с сохранением существующих данных.
Создание, смена статуса и отмена заказа выполняются в транзакциях.
Деньги хранятся в `Long` в целых тенге, без ошибок округления `Double`.

## Проверка

JUnit и Robolectric проверяют регистрацию клиентов, миграцию базы, создание заказов,
суммы по ценам из базы, остатки, отмену, одновременные изменения статуса, переполнение
чисел, поиск и правила каталога. Ручные сценарии — в `CHECKLIST.md`.

## Улучшения удобства

- Заказы: поиск по номеру (например, `#001`) и имени клиента, фильтры по статусу и кнопка сброса.
- Карточка клиента: редактирование имени и телефона, количество активных и выполненных заказов, создание заказа с уже выбранным клиентом.
- Один телефон нельзя случайно записать дважды с разными пробелами, скобками или дефисами. Разные национальные префиксы автоматически не заменяются.
- Нового клиента можно зарегистрировать прямо при оформлении заказа, сохранив корзину.
- В подборе товаров есть категории, их названия и количество в корзине; можно добавить несколько позиций и нажать «Готово».
- Сумма и оформление закреплены внизу; после сохранения открывается созданный заказ.
- При выходе из незавершённого заказа появляется подтверждение. После подтверждённого выхода корзина не сохраняется.
- Если цена изменилась, заказ не создаётся молча по новой цене: корзина обновляется и требуется повторное подтверждение.
- Если остаток изменился во время редактирования товара, устаревшая карточка не перезаписывает его.
- Ошибки товаров и категорий показываются в форме без потери введённых данных.
- Фильтры и открытая карточка клиента сохраняются при переключении вкладок.

## Проверка интерфейса

В `app/src/androidTest` проверяются поиск с фильтром, редактирование клиента, регистрация клиента внутри корзины, заказ без клиента с ручным вводом количества, подбор по категории, пополнение остатка и действия главной.

```powershell
.\gradlew.bat connectedDebugAndroidTest
```

Нужен запущенный Android-эмулятор или подключённый телефон. Если компонент Gradle UTP недоступен в кэше, тесты можно запустить напрямую:

```powershell
.\gradlew.bat assembleDebug assembleDebugAndroidTest
adb install -r app/build/outputs/apk/debug/app-debug.apk
adb install -r app/build/outputs/apk/androidTest/debug/app-debug-androidTest.apk
adb shell am instrument -w -r -e class com.nursetmobile.WorkflowTest com.nursetmobile.test/androidx.test.runner.AndroidJUnitRunner
```
