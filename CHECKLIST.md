# CHECKLIST — ручная проверка приложения

Инструкция для проверки работоспособности приложения «Учёт товаров и заказов».
Пройдите по шагам от начала до конца. Все действия выполняются на эмуляторе или устройстве с уже запущенным приложением (демо-данные создаются при первом запуске).

---

## 1. Главный экран

1. Откройте приложение.
2. Убедитесь, что отображаются 4 карточки-статистики: «Товаров», «Категорий», «Заказов», «Мало на складе».
3. Цифры в карточках должны совпадать с количеством записей на соответствующих вкладках.
4. Если есть товары с остатком ≤ 3 шт., карточка «Мало на складе» показывает их количество.
5. Нажмите кнопку «Перейти к товарам» — открывается вкладка «Товары».
6. Нажмите кнопку «Перейти к категориям» — открывается вкладка «Категории».
7. Нажмите кнопку «Перейти к заказам» — открывается вкладка «Заказы».

---

## 2. Товары

### Просмотр и поиск
1. Перейдите на вкладку «Товары».
2. Убедитесь, что список товаров отображается (при первом запуске — демо-данные).
3. Введите в строку поиска часть названия товара — список фильтруется по вводимому тексту (без учёта регистра).
4. Нажмите крестик в строке поиска — поиск очищается, показываются все товары.
5. Нажмите на категорию в горизонтальном списке фильтров — показываются только товары этой категории.
6. Нажмите «Все категории» — фильтр сбрасывается, показываются все товары.

### Добавление
1. Нажмите кнопку «+» внизу справа.
2. Заполните поля: Название, Категория (выберите чип категории), Цена, Количество.
3. Нажмите «Сохранить».
4. Товар появляется в списке.
5. Проверьте ошибки: откройте диалог ещё раз, оставьте пустое название или цену 0/отрицательную — появляются сообщения об ошибках, товар не сохраняется.
6. Попробуйте добавить товар с названием, которое уже есть в этой же категории (другим регистром) — появляется ошибка дубликата.

### Редактирование
1. Нажмите значок «карандаш» на карточке товара.
2. Измените цену или количество, нажмите «Сохранить».
3. Изменения отображаются в списке сразу.
4. Попробуйте изменить название на название другого товара той же категории — появляется ошибка дубликата.

### Удаление
1. Нажмите значок «корзина» на карточке товара.
2. Появляется диалог подтверждения «Удалить товар?».
3. Нажмите «Удалить» — товар исчезает из списка.
4. Нажмите «Отмена» — диалог закрывается, товар остаётся.
5. Попробуйте удалить товар, который есть в активном (Новый/В обработке) заказе — появляется сообщение «Нельзя удалить товар, который используется в активном заказе.», товар не удаляется.

### Остатки
1. Товар с остатком 1–3 шт. подсвечивается жёлтым/красным и подписью «⚠ Осталось N шт.».
2. Товар с остатком 0 показывает «Нет в наличии».
3. Если есть товары с малым остатком, сверху списка появляется красное предупреждение «Мало товара на складе: N».

---

## 3. Категории

### Просмотр
1. Перейдите на вкладку «Категории».
2. Убедитесь, что список категорий отображается (при первом запуске — демо-данные).

### Добавление
1. Нажмите кнопку «+» внизу справа.
2. Введите название категории, нажмите «Сохранить».
3. Категория появляется в списке.
4. Проверьте ошибки: откройте диалог ещё раз, оставьте пустое название — появляется сообщение об ошибке.
5. Попробуйте добавить категорию с уже существующим названием (другим регистром) — появляется ошибка дубликата.

### Редактирование
1. Нажмите значок «карандаш» на карточке категории.
2. Измените название, нажмите «Сохранить».
3. Новое название отображается в списке.
4. Попробуйте переименовать категорию в название другой категории — появляется ошибка дубликата.

### Удаление
1. Нажмите значок «корзина» на карточке категории.
2. Появляется диалог подтверждения.
3. Нажмите «Удалить» — пустая категория удаляется.
4. Нажмите «Отмена» — диалог закрывается, категория остаётся.
5. Попробуйте удалить категорию, в которой есть товары — появляется сообщение «Нельзя удалить категорию, поскольку в ней находятся товары.», категория не удаляется.

---

## 4. Создание заказа

### Открытие и выбор товаров
1. Перейдите на вкладку «Заказы».
2. Нажмите кнопку «+» внизу справа.
3. Открывается экран «Новый заказ» с пустой корзиной.
4. Нажмите «+» внизу справа (или кнопку «Выбрать товары»).
5. В появившемся диалоге выберите товар из списка (только товары с остатком > 0).
6. Товар появляется в корзине с количеством 1.
7. Нажмите «+» ещё раз и добавьте второй товар.

### Работа с корзиной
1. Для товара в корзине нажмите «+» (увеличить количество) — количество растёт, итоговая сумма пересчитывается.
2. Нажмите «−» (уменьшить количество) — количество уменьшается (минимум 1).
3. Кнопка «+» неактивна, если количество достигло остатка товара на складе — заказать больше остатка нельзя.
4. Нажмите значок «корзина» на позиции — товар удаляется из корзины.
5. Убедитесь, что внизу отображается карточка «Итого» с правильной суммой (цена × количество по каждой позиции).

### Создание заказа
1. Нажмите кнопку «Создать заказ».
2. Появляется сообщение об успехе, экран закрывается, открывается список заказов.
3. Остаток выбранного товара на вкладке «Товары» уменьшился на заказанное количество.

### Проверка ошибок
1. Откройте создание заказа, добавьте товар, затем на вкладке «Товары» уменьшите его остаток до 0.
2. Вернитесь в корзину и увеличьте количество товара выше нового остатка (или создайте заказ с количеством больше остатка) — появляется сообщение «Недостаточно товара на складе. Доступно: N шт.», заказ не создаётся, остатки не меняются.

### Отмена создания
1. Откройте создание заказа и нажмите крестик в шапке.
2. Вы возвращаетесь на список заказов, заказ не создаётся.

---

## 5. Список заказов

1. Перейдите на вкладку «Заказы».
2. Убедитесь, что список заказов отображается (при первом запуске пуст, затем появляются созданные заказы).
3. В шапке справа отображается счётчик «Заказов: N».
4. Нажмите на карточку заказа — открывается экран деталей заказа.
5. Нажмите кнопку «+» внизу справа — открывается экран создания нового заказа.

---

## 6. Детали заказа

### Просмотр
1. Откройте любой заказ из списка.
2. Убедитесь, что отображаются: номер заказа, статус (цветной чип), дата создания, список позиций (название, цена × количество, сумма) и итоговая сумма.

### Смена статуса (переходы)
1. Если статус «Новый», нажмите «В обработку» — статус меняется на «В обработке».
2. Если статус «В обработке», нажмите «Выполнен» — статус меняется на «Выполнен».
3. Если статус «Выполнен» или «Отменён», кнопок смены статуса нет, отображается текст «Заказ выполнен»/«Заказ отменён».

### Отмена заказа и возврат на склад
1. Запомните остаток товара из этого заказа на вкладке «Товары».
2. Откройте заказ в статусе «Новый» или «В обработке».
3. Нажмите «Отменить».
4. Появляется диалог «Отменить заказ №N? Товары вернутся на склад…».
5. Нажмите «Отменить» — статус меняется на «Отменён».
6. Вернитесь на вкладку «Товары» — остаток товара из отменённого заказа вернулся (увеличился на количество из заказа).
7. Повторно откройте отменённый заказ — кнопок действий нет.

### Повторная отмена
1. Откройте уже отменённый заказ — кнопки «Отменить» нет, отображается «Заказ отменён». Повторная отмена невозможна.

### Навигация
1. Нажмите крестик в шапке — вы возвращаетесь к списку заказов.

## Дополнительные проверки сквозных сценариев

1. **Недостаток остатка:** создайте товар с остатком 2, попробуйте заказать 3 шт. в одном заказе — ошибка «Недостаточно товара…».
2. **Один товар дважды в корзине:** добавьте один и тот же товар дважды (или увеличьте количество) — количество суммируется, остаток списывается суммарно, ошибка появляется, только если сумма превышает остаток.
3. **Цена из базы:** итоговая сумма заказа считается по цене товара из базы на момент создания (а не по цене, введённой вручную).
4. **Отмена возвращает всё:** отмена заказа с несколькими позициями возвращает на склад все позиции.

## Клиенты и связь с заказами

1. Откройте «Клиенты», добавьте имя и телефон. Пустое имя и телефон короче 7 цифр не сохраняются.
2. Найдите клиента по части имени в другом регистре и по цифрам телефона.
3. Создайте заказ с товарами и выберите клиента. До выбора клиента кнопка создания недоступна.
4. Проверьте имя клиента в списке заказов и деталях заказа.
5. Откройте клиента: заказ отображается в его истории; нажатие открывает детали.
6. Измените статус заказа, вернитесь в историю клиента: статус обновился.
7. Проверьте главный экран на небольшом устройстве и при увеличенном шрифте: содержимое прокручивается.
8. При обновлении установленной версии с базой v1 существующие товары и заказы сохраняются; старые заказы остаются без клиента.

## Поиск, оформление и защита данных

1. В «Заказах» найдите заказ по `#001` и по имени клиента; совместите поиск с фильтром «Активные».
2. Убедитесь, что «Сбросить фильтры» возвращает полный список при пустом результате.
3. Откройте клиента, измените имя и телефон: история остаётся у этого клиента, старое имя в заказе остаётся снимком на момент создания.
4. Попробуйте добавить номер существующего клиента с другими пробелами и скобками: повторная запись не создаётся.
5. Из карточки клиента нажмите «Создать заказ»: клиент уже выбран.
6. При оформлении создайте нового клиента, добавьте несколько товаров без закрытия подбора; проверьте счётчики «В корзине».
7. Нажмите системную кнопку «Назад»: подтвердите продолжение и убедитесь, что корзина сохранилась.
8. Во время создания заказа кнопки повторного сохранения недоступны.
9. Введите дубликат товара или категории: форма остаётся открытой, введённый текст сохраняется и видна ошибка.
10. Переключите вкладки после поиска заказа или открытия клиента: поиск и карточка остаются на месте.
11. Проверьте детали заказа при увеличенном шрифте: позиции, сумма и действия прокручиваются.
